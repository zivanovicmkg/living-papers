# Living Papers

Published research rebuilt as interactive pages for readers and structured data for AI agents (MCP).
Marko Živanović · Biology 2.0 · https://papers.biology2.net

| Paper | Live | Data |
|---|---|---|
| Živanović M. et al. *Pharmaceutics* 2023, 15, 1628 · doi:10.3390/pharmaceutics15061628 | [/pharmaceutics-2023/](https://papers.biology2.net/pharmaceutics-2023/) | `paper.json`, `data.json` |

Each paper lives in its own folder: `index.html` (visual page), `paper.json` (all text: metadata, question, methods, limitations, quotes, references, provenance) and `data.json` (all numbers). The page renders only from these two files; the agent layer reads the same files. Paper content is CC BY 4.0 as published; cite the original article.
